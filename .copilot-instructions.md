# GitHub Copilot Instructions for Trading Bot ML Price Validation

## CRITICAL: Trading Strategy Flow

### Entry Price Strategy
1. **ML extracts GREY ENTRY ZONE** from chart scale (e.g., 146.610 - 146.620 for USDJPY)
2. **Calculate entry price** as center of grey zone (146.615)
3. **Place LIMIT order** at that exact entry price
4. **Calculate SL/TP** relative to the entry price

### Example Flow: USDJPY Signal
```
Chart Analysis → Grey Zone: 146.610-146.620
Entry Price = (146.610 + 146.620) / 2 = 146.615
Place LIMIT BUY at 146.615
Stop Loss = Entry - 2% = 143.68
Take Profit = Entry + 2% = 149.55
```

## CRITICAL: ML Price Extraction Rules

### The Problem We're Solving
- ML systems extract OCR text from trading charts
- Charts have Y-axis scale markers (like 2, 7, 13) that are NOT trading prices
- ML must distinguish between chart scale artifacts and actual price levels

### Price Validation Rules by Symbol

#### JPY Pairs (USDJPY, GBPJPY, EURJPY, etc.)
- **Valid Range**: 50 - 250
- **Current Typical**: USDJPY ~146.615, GBPJPY ~185, EURJPY ~160
- **REJECT**: Any price < 50 (these are chart scale markers)
- **REJECT**: Any price > 250 (unrealistic for JPY pairs)
- **Example**: If OCR extracts "7, 2, 13, 146.615, 147.2" → KEEP only 146.615, 147.2

#### Gold/XAUUSD
- **Valid Range**: 1000 - 4000
- **Current Typical**: ~2650
- **REJECT**: Any price < 1000 (chart scale markers)
- **Example**: If OCR extracts "5, 10, 2650.50, 2651.20" → KEEP only 2650.50, 2651.20

#### Major Forex (EURUSD, GBPUSD, etc.)
- **Valid Range**: 0.5 - 2.0
- **Current Typical**: EURUSD ~1.10, GBPUSD ~1.30
- **REJECT**: Single digits without decimals
- **REJECT**: Prices < 0.5 or > 2.0

#### Indices (NAS100, SPX500)
- **Valid Range**: 10000 - 25000
- **Current Typical**: NAS100 ~20000, SPX500 ~5500
- **REJECT**: Small numbers < 1000 (chart coordinates)

### Implementation Guidelines

#### DO THIS ✅
```typescript
// Simple sanity check filters
if (symbol.includes('JPY') && price < 50) {
  logger.warn(`Rejected JPY price ${price} - chart scale artifact`);
  return false;
}

if (symbol.includes('XAUUSD') && price < 1000) {
  logger.warn(`Rejected Gold price ${price} - chart scale artifact`);
  return false;
}

// General rule: reject obvious single digits
if (price < 10) {
  logger.warn(`Rejected price ${price} - single digit chart marker`);
  return false;
}
```

#### DON'T DO THIS ❌
```typescript
// Don't overcomplicate with market data APIs
const currentPrice = await getMarketPrice(symbol); // UNNECESSARY
if (Math.abs(price - currentPrice) > tolerance) { // TOO COMPLEX
```

### Key Principles

1. **Keep It Simple**: Use basic range validation, not complex market data
2. **Chart Scale Recognition**: Single digits are usually Y-axis markers, not prices
3. **Symbol-Specific Logic**: JPY pairs behave differently than USD pairs
4. **Log Rejections**: Always log why a price was rejected for debugging

### Common Chart Scale Artifacts to Reject

- **JPY Charts**: 2, 5, 7, 10, 13, 15, 20 (Y-axis scale)
- **Gold Charts**: 5, 10, 20, 50 (price scale increments)
- **Forex Charts**: 0, 1, 2, 5 (pip scale markers)
- **Index Charts**: 100, 200, 500 (point increments)

### Real Example - USDJPY at 146.615

**OCR Input**: "Entry: 7, Stop: 2, Target: 13, grey zone: 146.610-146.620, levels: 147.200, 145.800"

**Before Fix**: 
- Extracted grey entry: [7, 2] ❌
- Entry price: 4.5 ❌ 
- LIMIT order at 4.5 ❌

**After Fix**: 
- Extracted grey entry: [146.610, 146.620] ✅
- Entry price: 146.615 ✅
- LIMIT order at 146.615 ✅

**Logic**: Rejected 7, 2, 13 because they're < 50 for JPY pair, kept realistic grey zone levels

### Grey Zone Extraction Priority

The ML should prioritize extracting the **grey entry zone** because:
1. This is where LIMIT orders are placed
2. All SL/TP calculations are relative to this entry
3. Wrong entry = wrong entire trade setup

**Code Pattern**:
```typescript
// ML identifies grey zone from chart
greyEntry: { min: 146.610, max: 146.620, confidence: 0.95 }

// Executor calculates entry price  
entryPrice = (greyEntry.min + greyEntry.max) / 2; // 146.615

// Places LIMIT order at entry price
createLimitBuyOrder(symbol, volume, entryPrice);
```

### Testing Your Implementation

```typescript
testPrices('XAUUSD', [5, 10, 2650.50, 2651.20]);    // Should keep only 2650.50, 2651.20

```

### When in Doubt

If you're unsure about price validation:
1. Look at current market prices for that symbol
2. Ask: "Would a trader actually set a stop at 7 for USDJPY?" (No!)
3. Err on the side of rejecting suspicious values
4. Always log the rejection reason

Remember: **It's better to miss a trade than execute a trade with wrong levels!**
