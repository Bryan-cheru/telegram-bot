## 🚀 **Installation Instructions**

### For Setup Installer:
1. Download `Telegram Trading Bot-1.0.0-Setup.exe`
2. Right-click and select "Run as administrator" (recommended)
3. Follow the installation wizard
4. Choose installation directory (default: `C:\Program Files\Telegram Trading Bot`)
5. Select additional tasks (desktop shortcut, Start Menu)
6. Complete installation
7. Launch from desktop shortcut or Start Menu

### For Portable Version:
1. Download `Telegram Trading Bot-1.0.0-Portable.exe`
2. Create a folder for the application (e.g., `TelegramTradingBot`)
3. Move the portable executable to this folder
4. Double-click to run - no installation needed!
5. Application will create necessary files in the same folder

### For ZIP Archive:
1. Download and extract `Telegram Trading Bot-1.0.0-win.zip`
2. Extract to desired location
3. Run `Telegram Trading Bot.exe` from the extracted folder
