# Telegram Trading Bot - Desktop App

## 🚀 Features

Your professional Telegram Trading Bot now has a **beautiful Windows desktop interface**!

### ✨ **What You Get:**

- **🎛️ Complete Bot Control**: Start, stop, restart your trading bot with one click
- **📊 Real-time Dashboard**: Live status, uptime, configuration health checks
- **📋 Live Logs**: Real-time log streaming with color-coded levels
- **💹 Trade Monitoring**: Track your trades and performance statistics
- **⚙️ Settings Panel**: Configure trading parameters and view environment status
- **📖 Built-in Help**: Complete setup guide and feature documentation

### 🖥️ **Professional UI:**
- Modern, clean interface with professional styling
- Real-time status indicators and health monitoring
- Organized navigation with dedicated sections for all features
- Responsive design that works on different screen sizes
- Dark theme logs console for easy reading

### 🎯 **Perfect For:**
- **Live Trading**: Monitor your bot's performance in real-time
- **Development**: Debug and test your trading strategies
- **Portfolio Management**: Track trades and analyze performance
- **Configuration**: Easy setup and environment management

---

## 📦 **Installation & Usage:**

### **Option 1: Run in Development Mode**
```bash
npm run electron:dev
```

### **Option 2: Build Windows Installer** 
```bash
npm run electron:dist
```
This creates a professional Windows installer in `dist-electron/`

### **Option 3: Just Run Electron**
```bash
npm run electron
```

---

## 🎮 **Controls:**

- **Ctrl+S**: Start Bot
- **Ctrl+T**: Stop Bot  
- **Ctrl+R**: Restart Bot
- **Ctrl+,**: Open Settings

---

## 💡 **Tips:**

1. **First Time Setup**: Configure your `.env` file before starting
2. **Monitor Logs**: Keep the logs tab open to see real-time activity
3. **Check Status**: The header shows bot status and uptime
4. **Safe Testing**: Use simulation mode first before live trading
