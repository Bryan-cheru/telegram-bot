Getting Started

🚀 Quick Setup

  1. Configure your environment variables in the .env file
  2. Set up your Telegram bot token from @BotFather
  3. Configure MetaAPI token and account ID
  4. Add the bot to your trading signals channel
  5. Click "Start Bot" to begin trading

📊 Features

  • Universal Chart Parsing: Supports all forex pairs, indices, and commodities
  • Visual Zone Detection: Grey zones = Entry, Red zones = Targets
  • Risk Management: Adaptive stop losses and position sizing
  • Real-time Monitoring: Live logs and trade statistics
  • Cloud Trading: MetaAPI integration for remote execution

⚙️ Supported Instruments

  • Forex Pairs: All 6-letter pairs (EURUSD, GBPUSD, etc.)
  • Indices: NAS100, US30, SPX500, etc.
  • Commodities: XAUUSD (Gold), XAGUSD (Silver), Oil, etc.

🛡️ Safety Features

  • Multi-layer result filtering to prevent false trades
  • Position size limits and risk percentage controls
  • Channel-specific signal processing
  • Comprehensive error handling and logging

💡 Tips

  • Start with simulation mode to test the bot
  • Use small position sizes when starting
  • Monitor the logs regularly for any issues
  • Ensure your MetaAPI account is properly funded
