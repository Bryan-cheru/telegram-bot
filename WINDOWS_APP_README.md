## 🚀 Quick Start

### Option 1: Double-click Launcher (Recommended)
1. Double-click `launch-app.bat` in the project folder
2. The Windows desktop application will launch automatically

### Option 2: PowerShell Launcher
1. Right-click `launch-app.ps1` → "Run with PowerShell"
2. Application will check dependencies and launch

### Option 3: Manual Launch
1. Open PowerShell/Command Prompt in the project folder
2. Run: `npm run electron`
